## Reading This Map

**Vertical depth** represents dependency: concepts lower in the tree depend on concepts above them. For example, "ecology of psychotechnologies" depends on understanding "counteractive dynamical system" which depends on understanding "parasitic processing" which depends on understanding "relevance realization."

**Horizontal grouping** represents function: concepts at the same level within a group serve the same ontological function (e.g., all the items under "Enables participatory knowing" are different articulations of the same structural feature of generative ontology).

**Cross-references** between branches are extensive but not drawn to preserve readability.
