# Explanations

Core concepts behind Open Wisdom Views, explaining how and why foundational assumptions shape AI behavior.

## Structure

Root-level files are concise entry points linking to detailed analyses:

- **generative-ontology.md** — The core concept: priors constitute experience, not filter it
- **degenerative-patterns.md** — How current AI recapitulates the meaning crisis
- **design-principles.md** — Five structural features of generative ontologies as design criteria
- **sources.md** — Key thinkers (Chandaria, Vervaeke, Almaas, Wilber) with entry points
- **meaning-crisis/** — Detailed analysis of Vervaeke's 51-episode series applied to AI

## Reading Order

For the core argument: generative-ontology → degenerative-patterns → design-principles. For depth: meaning-crisis/00 overview, then follow links by interest. For the neuroscientific mechanism: sources → Chandaria synthesis in resources/.
